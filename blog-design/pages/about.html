关于我

写代码，也写点别的

计算机科学在读学生，对机器学习与系统编程有浓厚兴趣。日常游走于算法推导和终端命令之间，偶尔也读几页认知科学的论文，试图理解自己写代码时的大脑在做什么。

相信好的工程不仅是把功能做出来，更是用恰当的抽象把复杂的事情变简单。写博客既是记录学习轨迹的方式，也是梳理思路的练习。

技术栈以 Python 和 Rust 为主力，前端用 React 和 Astro 搭建。对 LLVM 编译基础设施有持续的好奇心，也喜欢用 Go 写一些趁手的命令行工具。

兴趣领域

机器学习

从理论推导到工程落地，关注模型可解释性与高效训练。

系统编程

Rust、LLVM 与操作系统内核，追求零成本抽象。

认知科学

探索心智模型与计算建模的交叉领域。
